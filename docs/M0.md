# M0 — Foundation

**Done when** (DESIGN §11): repo, CLAUDE.md, perf overlay, device tiers, atlas pipeline, music player, deploy action; an empty pixel iso grid at 60 fps on a mid phone, in landscape.

Work top to bottom. Each step ends with a commit.

1. **Scaffold** — `package.json`, Vite + TypeScript strict, per-layer tsconfigs (`sim/` without the DOM lib), ESLint boundary rules, Vitest, `CREDITS.md` (music: Gemini + its terms), `BACKLOG.md`.
   *Done:* `npm run dev`, `build`, `test`, `typecheck` pass on an empty page.
2. **Deploy action (early, to de-risk)** — `.github/workflows/deploy.yml`: on push to `main` → `npm ci`, typecheck, test, build → check out `aungkhantmin21/aungkhantmin21.github.io` with `DEPLOY_TOKEN` → `rsync -a --delete dist/ site/games/laphat-yay-sine/` → `git add games/laphat-yay-sine` only → commit if changed → push. Add a `concurrency` group. Sanitise Rollup file names so none start with `_` (Jekyll drops them).
   *Done:* a "hello" page is live at aungkhantmin21.github.io/games/laphat-yay-sine/ and nothing else in the site repo changed.
3. **Size budget check** — `tools/check-size` fails CI if `dist/` without music is over 3 MB.
4. **Landscape shell** — `index.html` with `viewport-fit=cover`, `100dvh`, `touch-action: none`, `overscroll-behavior: none`, pinch/double-tap page zoom blocked; rotate-phone screen in portrait; on Android, fullscreen + `screen.orientation.lock('landscape')` on first tap (failures ignored).
5. **Pixel stage** — Pixi app; internal RenderTexture 270 px high with width from aspect; one integer upscale pass computed in device pixels; resize handling; WebGL context lost/restored handling.
6. **Frame loop** — rAF with fixed step + interpolation, 30 fps cap option, idle drop, stop when hidden.
7. **Worker + protocol** — `shared/protocol.ts`, `shared/diff.ts`, `game/bridge.ts`, `sim/worker.ts`: init/ready, 10 Hz empty frames, buffer recycling, version check.
   *Tests:* diff encode/decode round-trip; tick determinism from a seed.
8. **Iso grid** — `shared/iso.ts` (tested); placeholder floor grid (e.g. 64×48) rendered into static chunk textures; drag to pan; pinch/wheel zoom snapped to whole scales; spatial-hash culling.
9. **Art style guide v0 + atlas pipeline** — `docs/ART_STYLE.md`, `art/palette.hex` (≤ 32 colours), a few CC0 placeholder tiles (licences in CREDITS.md), `tools/pack-atlas` → 1024² WebP + PNG + JSON, loader with WebP→PNG fallback.
10. **Device tiers** — `platform/tier.ts`: start at Low, run the 2 s benchmark after the first frame, combine with `hardwareConcurrency` / `deviceMemory`, persist in IndexedDB `meta`, overridable in settings.
11. **Perf overlay** — `?debug=1`: fps, frame time (avg / p95), draw calls (counted by a GL wrapper in debug builds), texture memory estimate, JS heap (where available), sim tick ms from the worker.
12. **Myanmar font + i18n** — `tools/subset-font` → Noto Sans Myanmar WOFF2 keeping the full ranges U+1000–109F, U+AA60–AA7F, U+A9E0–A9FF, Basic Latin, digits and common punctuation, with GSUB/GPOS shaping (never subset by my.json text); `ui/i18n/my.json`; title text in the DOM. Check stacked consonants on Android Chrome and iOS Safari.
13. **Music player** — `audio/music.ts`: unlock on first tap; `canPlayType` + decode-failure fallback ogg → m4a; files loaded from Vite-imported hashed URLs (music.json names are labels only); loop points from `music.json`; 4 s equal-power crossfade; lazy load after the first frame; ≤ 2 decoded buffers; resume after interruptions; debug buttons to switch tracks.
14. **M0 gate** — empty iso grid at 60 fps on a mid phone in landscape; steady 30 fps with 6× CPU throttling; budgets checked in the overlay; iPhone check (rotate screen, audio unlock, m4a loop seamless). Record results below.
